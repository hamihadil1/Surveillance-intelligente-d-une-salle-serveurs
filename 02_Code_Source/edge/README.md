\# Firmware Edge (ESP32)



Ce dossier contient le code C++ pour le nœud Edge (ESP32), développé avec FreeRTOS.



\## Lien de simulation Wokwi

https://wokwi.com/projects/479794285080424449



\## Fonctionnalités implémentées

\- 3 Tâches FreeRTOS (Acquisition, Inference, Communication).

\- Lecture de 3 capteurs (DHT22, Potentiometer).

\- Communication MQTT (broker.emqx.io).
