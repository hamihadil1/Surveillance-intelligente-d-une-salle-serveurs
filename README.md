# \##  Description du Projet

# Ce projet implémente une architecture Edge-Fog-Cloud pour la surveillance thermique d'un Data Center. Un modèle de Machine Learning embarqué (TinyML) sur un ESP32 (simulé sous Wokwi) permet de détecter les anomalies (surchauffe, obstruction d'air) en temps réel et de déclencher un refroidissement d'urgence.
